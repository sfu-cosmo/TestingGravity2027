HTML Content
------------

Text blocks that go into layout template. Content should be edited here, *not in the Hype document*, to keep changes under revision control. These go into the following scenes:

- `blurb.html`  -  main text on `Welcome` scene (landing page)
- `conduct.html`  -  code of conduct in `Conduct` scene
- `directions.html`  -  directions on `Travel Info` scene (left panel)
- `fees.html`  -  main text on `Register` scene
- `gauge.html`  -  timeline gauge on `Register` scene
- `hotels.html`  -  hotel info on `Travel Info` scene (right panel)
- `local.html`  -  links on `Local Info` scene (below Google map)
- `organizers.html`  -  topics and organizers on `Welcome` scene (right panel)
- `speakers.html`  -  speakers and participants on `Welcome` scene (left panel)
- `travel.html`  -  main text on `Travel Info` scene
- `venue.html`  -  conference location on `Travel Info` scene (right panel)

#### Index by the scene

- ***`Welcome`***: `blurb.html`, `speakers.html`, `organizers.html`
- ***`Register`***: `fees.html`, `gauge.html`
- ***`Participants`***: `../participants/participants.html`
- ***`Program`***: `../program/program.html`
- ***`Travel Info`***: `travel.html`, `directions.html`, `venue.html`, `hotels.html`
- ***`Local Info`***: `local.html`
- ***`Conduct`***: `conduct.html`

#### Head HTML styling

- `head.html`  -  global CSS and Javascript styling, leave it alone
